# Posters

Every poster on the site, one image per poster (PNG, JPG, or WebP; the
full-resolution export is fine). Name files event, year, then topic, lowercase
with hyphens: `iticse-2025-self-explanation-timing.png`.

A file here does not show up on its own: each poster also needs an entry in
`posterItems` in `data/publications/index.js` for its title, venue, and
citation. See "Adding a Poster" in the main README.
